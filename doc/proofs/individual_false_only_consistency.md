# Consistency of the five false_only boolean(false) conjectures

Reviewed on 2026-09-28. Claim: for each of the five points

| point | F = \x. E[x] |
|---|---|
| probe_cycle_and_false | E[x] = x false false |
| probe_cycle_if_false | E[x] = x false x |
| probe_cycle_and_or | E[x] = (x true x) false false |
| value_map_two_cycle | E[x] = x A2 false, A2 = \p. \q. true |
| value_map_three_cycle | E[x] = x A3 false, A3 = \p. \q. \r. \s. true |

with M = Y F the point's program (Y the prelude's `\f. (\p. f (p p)) (\q. f (q q))`,
true = \t. \f. t, false = \t. \f. f), the scored test of template
boolean(false), T = \a. M y a (y free), satisfies is_identity(T):
lambda beta eta + (T = \x. x) is consistent.

## Reduction to M = false

Let Th be the lambda theory lambda beta eta + {N = false : N in G}, G the set of
closed terms defined below, with M in G. Th proves M = false, hence
T = \a. M y a = \a. false y a = \a. a, for every y. So lambda beta eta + (T = \x. x)
is contained in Th, and it suffices to prove Th consistent.

## The set G

Fix one of the five points. Write I = \y. y, D = \p. F (p p), D' = \p. E[p p],
and Y_n = \f. f^n (D_f D_f) for n >= 0, where D_f = \p. f (p p) (so Y_0 = Y up to
alpha). E has k occurrences of x (k = 1, or 2 for if_false and and_or); write
E[T_1, ..., T_k] for E with its occurrences filled independently. G is the set of
closed terms generated by

    T ::= Y_n F            (n >= 0)
        | P Q              (P, Q in {D, D'})
        | F T
        | E[T, ..., T]
        | I T
        | T false false
        | false

M = Y_0 F is in G. The following four facts are checked by inspection of the
productions.

(G1) G is closed under one-step beta eta reduction. The redexes of a term of G:
- Y_n F: the root gives F^n (D D), a stack of F-nodes over the leaf D D; the
  only redex inside Y_n (D_f D_f, f free) gives Y_{n+1}.
- P Q: the root gives F (Q Q) when P = D, and E[Q Q, ..., Q Q] when P = D';
  inside, D reduces to D' (its only redex, F (p p) -> E[p p]); D' is normal.
- F T: the root gives E[T, ..., T]; F itself is normal.
- E[T_1, ..., T_k]: the only abstraction a production can put in operator
  position is false (every other production is an application), so a redex at
  the E-node exists only when the child in operator position is false, and then
  it is `false C -> I` for the first argument C; the result is again in G:
  and_false, value_map: (false C) false -> I false; if_false: (false false) T_2
  -> I T_2; and_or: ((false true) T_2) false false -> (I T_2) false false, an
  instance of `T false false`.
- I T: the root gives T.
- T false false: a redex at the node only when T = false: (false false) false
  -> I false.
- Redexes inside children are handled by induction on the term.
There are no eta redexes: the only abstractions occurring are the fixed parts
Y_n, D_f, D, D', F, I, false, true, A2, A3 and their subterms, none of which is of
the form \z. N z with z not free in N (F for if_false is \x. (x false) x, and x
is free in x false).

(G2) Every term of G other than false is an application (every production but
false is one), hence not an abstraction.

(G3) If N in G has a subterm occurrence N' in G, then N with that occurrence
replaced by false is in G. The closed subterms of a term of G are its
production nodes and the closed subterms of the fixed parts; the latter are
Y_n, D, D', F, I, true, A2, A3 and their closed subterms, all abstractions other
than false, hence not in G by (G2), and false itself (replacing false by false
changes nothing). Every child position of every production accepts any T, so
replacing a node by false gives a term of G.

(G4) true is not in G, by (G2): it is an abstraction other than false.

## Confluence

Let rho be the rule N -> false for N in G, N /= false, applied at any position
(the terms of G are closed, so contexts and substitutions do not affect them).
Let R = beta eta U rho. Write rho|| for the parallel contraction of any set of
rho-redex occurrences.

(C1) rho|| has the diamond property. Given M ->rho|| M1 (occurrences P1) and
M ->rho|| M2 (occurrences P2), take M3 = M with every maximal occurrence of
P1 U P2 replaced by false. An occurrence q maximal in P1 U P2 that is in P2 but
has members of P1 inside it: in M1 it holds N_q with those inner occurrences
replaced by false, which is in G by (G3) applied repeatedly, so M1 ->rho|| M3;
symmetrically M2 ->rho|| M3. Hence rho* = rho||* is confluent.

(C2) beta eta and rho|| commute in one step: if M ->betaeta M1 and M ->rho||
M2, there is M3 with M1 ->rho|| M3 (possibly zero occurrences) and M2 ->betaeta
M3 in at most one step. Cases on the contracted redex r and a replaced
occurrence N in G:
- r inside N: N -> N' in G by (G1); M1 ->rho|| M2, and M3 = M2.
- N inside r = (\z. B) Q, in B or in Q: N is closed, so contracting r copies,
  keeps or erases N unchanged; M1 ->rho|| M3 replacing the residuals, and M2 ->
  M3 by contracting the same redex (whose parts now hold false).
- r = \z. B z (eta) with N inside B: likewise.
- r = \z. N z with N the replaced occurrence: M1 = C[N] ->rho C[false], and
  M2 = C[\z. false z] ->eta C[false].
- N the operator of r: impossible, N is not an abstraction (G2).
- r and N disjoint: trivial.
By the usual tiling argument, ->betaeta* and ->rho||* commute.

(C3) beta eta is confluent (Barendregt 1984, Theorem 3.3.9). By (C1), (C2) and
the Hindley-Rosen lemma (Barendregt 1984, Proposition 3.3.5), R is confluent.

## Consistency

Convertibility under R is equality in Th. true and false are R-normal: they are
beta eta normal; their closed subterms are themselves only, and true is not in
G (G4) while false is excluded from rho. Two distinct R-normal forms are not
R-convertible when R is confluent, so Th does not prove true = false; Th is
consistent. By the reduction above, lambda beta eta + (T = \x. x) is consistent
for each of the five points: is_identity(T) holds, as conjectured, and a
reading that succeeds on these five scored tests is correct.

## Remarks

- The argument never uses an atom or the judge's reading; it is about the
  published test and the point's program only.
- Nothing in it depends on which closed normal term B stands in `x A B` beyond
  the checks in (G1): false in operator position is the only abstraction a
  production produces there, and each collapse stays in G.
