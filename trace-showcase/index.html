Each page plays one trace: the program the compiler started from, then one term per step. A trace holds only the commands, and the start is written beside it; the player computes every step's term by replaying the commands from the start. Use the buttons or type a step number; the URL hash keeps the position, the view and the shared subterms inlined.

The two buttons at the right of the control bar switch between the term drawn as nested boxes and the term as its text. Both write each shared subterm once, under its name, and refer to it by that name where it occurs; a click on the name β-reduces it into its occurrences, and the button on an inlined occurrence binds it again. The node the step rewrote is highlighted.
